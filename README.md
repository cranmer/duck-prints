# Duck Stamp Prints, 1981–1991

A gallery of 21 framed duck stamp prints: ten Federal Duck Stamp prints (1981-82 to 1990-91), the first ten Arkansas state duck stamp prints (special series 105/600), and a 1984 reissue of Ding Darling's 1934 design for the first Federal Duck Stamp.
